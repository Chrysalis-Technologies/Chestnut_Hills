# v0.4.0 — Offline bird calls

- Record a twelve-second bird call and identify it locally with the bundled BirdNET 2.4 FP16 model.
- Replay the clip, explicitly confirm a suggested species or Unknown call, and save notes with optional device GPS.
- Browse saved bird observations, replay recordings, correct identifications, edit notes, and delete recordings.
- Bird observations appear alongside tree sightings on the existing offline map, with separate destinations and labeled colors.
- Microphone access is requested only when starting a recording. Leaving the screen, locking the phone, or canceling ends capture.
- No internet permission, network service, model download, or background listening. Bird recordings and their database are stored outside Android backup; automatic backup and device transfer are disabled for app data.
- Includes offline BirdNET credits and CC BY-NC-SA 4.0 license. The model is restricted to noncommercial use unless separately licensed.

BirdNET scores are suggestions, not calibrated probabilities. Some non-bird animals are included; no regional filter is applied. GPS can be absent if permission is denied or a fix is unavailable. Existing tree CSV/GeoJSON exports contain tree sightings only. Unsaved clips are discarded when the app process exits. Saved recordings are removed if app data is cleared or the app is uninstalled.

Tree model, labels, species list, image preprocessing, and confidence thresholds are unchanged.
