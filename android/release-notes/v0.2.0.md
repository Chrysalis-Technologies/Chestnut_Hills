Save and manage tree sightings, completely offline.

- Save the top tree, another candidate, or **Unknown tree** with a timestamp and private JPEG photo.
- Prefer a selected original photo's EXIF GPS; otherwise use device GPS, including in airplane mode.
- Ask for optional location access only when saving. Save without a fix after 20 seconds, or skip the wait.
- Browse newest-first sightings; open the field guide, edit notes, change the tree, and confirm deletion.
- Share CSV or GeoJSON exports using Android's share sheet. Sightings without locations remain in both exports.
- No internet permission, Play Services, or network dependency. The model, preprocessing, and species list are unchanged.

Version code 2 uses the same application ID and shared test signing key as v0.1.0, so it is
configured for an in-place update. The update/install path and manual GPS, photo metadata,
editing/persistence, and share-sheet checks have **not been run on a physical device yet**.
Approximate-only location permission saves without a device GPS fix. Photo providers can omit
EXIF metadata; in that case the app tries device GPS. No map is included in this version.

Signed with the existing shared test key; not intended for an app store.
