# NY Tree ID v0.3.0 — illustrated guide and offline sightings map

- Illustrated guide entries with bark, leaves/needles, branches/buds, fruit/nuts/cones,
  and seasonal reference images. Captions identify the example species; image credits,
  licenses and source references are available offline.
- Spring, summer, autumn and winter identification cues for all 99 guide entries.
  Timing varies across New York; grouped entries and cultivars can vary.
- The collection includes labeled botanical illustrations. The weeping-willow fruit
  reference is explicitly labeled as a related hybrid comparison.
- Map saved sightings on a bundled New York overview. Pan, zoom, fit all sightings,
  tap numbered pins, or open an identification from the map's accessible list.
  Overlapping pins offer a list of sightings. Unknown trees are included; sightings
  without coordinates remain in the sightings list.
- Import a raster MBTiles file (PNG, JPEG or WebP, up to 1 GiB) for detailed offline
  background mapping. The app copies the file privately and preserves the previous
  map when validation fails. Vector PBF files are not supported. Remove an imported
  map to return to the overview without changing the source file or sightings.
- Version code 3. No database migration, model changes, additional runtime dependencies,
  or INTERNET permission.

Manual device testing, including an upgrade over v0.2.0 on the XCover, has **not** been run.
This change is submitted for review; a release has not been published.
